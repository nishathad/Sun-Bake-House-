SUN BOND phone-installable PWA

1. Upload the entire folder contents to an HTTPS web host. Keep index.html, manifest.webmanifest, sw.js and icons/ together.
2. Open the HTTPS website on Android Chrome.
3. Tap Chrome menu (⋮) -> Add to Home screen / Install app.
4. Launch SUN BOND from the new home-screen icon.

A PWA cannot be installed directly from a local file:// URL. It must be served from HTTPS (localhost is also allowed for development).
